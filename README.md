# Sit Here

Someone is here. Then they choose.

A one-screen page. No account. No setup. Not medical care. Not a crisis line.

- **Sit with me** — quiet presence. Occasional few words. A timer they do not have to watch.
- **Distract me** — short dry lines, optional on-device loops.
- **What do you need right now?** — sit, distract, music, listen, or quiet. Or type. No diagnosing.

Live: https://schmidtweston-ship-it.github.io/sit-here/

Loops in this folder are generated tones, not a subscription.
